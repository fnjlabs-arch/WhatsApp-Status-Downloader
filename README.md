# SadSha Status Saver

Save WhatsApp statuses (photos and videos) directly to your device — view
them in the app, tap download, keep them forever. No login required.

## Features

- **Easy status downloading:** download any WhatsApp status (image or video) directly to your device.
- **WhatsApp Business too:** switch between WhatsApp and WhatsApp Business statuses.
- **Saved tab:** everything you downloaded, in one place.
- **Share / repost:** share downloaded statuses with others.
- **No login required:** direct access to your saved statuses.

## How to use

1. Open SadSha Status Saver.
2. View WhatsApp statuses within the app.
3. Select the statuses you want to download.
4. Tap the download button to save them to your device.

Saved statuses go to `Documents/SadSha Status Saver` on your device.

## Build it

1. Clone the repository.
2. Open the project in Android Studio.
3. Build and run the app on your Android device.

Or use the GitHub Actions workflows: `Build debug APK` (test build, branch
`sadsha-remix`) and `Build release AAB` (Play Store release — needs Qasim's
own release keystore in the repository secrets).
